# 設計筆記

## Tokens
- 色：paper #FFFFFF、mist #EEF4F4（teal 淡面）、ink #1A1F27、slate #5B6470、teal #3F8C92、teal-deep #2F6E73、mint #8CFFD2（只用一次：0.2%）、rust #C4573A（逾期）
- 字：Bricolage Grotesque（拉丁字與數字、大數字）＋ Noto Sans TC（中文）。級距 14 / 16 / 18 / 28 / 40 / 88
- 版：「帳冊邊欄」——每節左側 320px 固定邊欄放節號、章、標題、一句話結論與大數字；右側舞台放圖。全站左對齊
- 原則：邊欄恆定、舞台變化；分隔靠細線不靠陰影；只有真正的序列（流程步驟）才有編號；把大膽用在大數字上

## 對照「通用預設」後的修正
- 白底 + teal 產品風是需求指定，保留；但拿掉圓角卡片＋灰陰影套件，1-3 改為以細線分格的 3×2 表格
- 不用全大寫 eyebrow、不用「·」串接、不在按鈕文字後加 →
- 沒有進場動畫；唯一的動效是 2-2 前/後切換（回應使用者操作）
