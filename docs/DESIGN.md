# 設計筆記

## Tokens
- 色：paper #FFFFFF、mist #EEF4F4 / mist-2 #E1ECEC（teal 淡面）、line #D6DDE0（分隔線）、ink #1A1F27、slate #5B6470（次要文字）、teal #3F8C92、teal-deep #2F6E73、mint #8CFFD2（只用一次：0.2%）、rust #C4573A / rust-tint #F7E6E1（逾期）
  - 相對慧景官網原色的調整：次要文字用 slate 取代 #2B323D（對比更柔）、深 teal 用 #2F6E73 取代亮版 #5BACB1（白底上需要更深才可讀）
- 字：Bricolage Grotesque（拉丁字與數字、大數字）＋ Noto Sans TC（中文）。級距 13 / 14 / 15 / 16 / 17 / 20 / 22 / 24 / 28（節標題）/ 34 / 40（公式、大字）/ 52 / 72（大數字）
- 版：「帳冊邊欄」——每節左側 320px 固定邊欄放節號、章、標題、定義／問題／解決方案與大數字；右側舞台放圖。全站左對齊；唯一例外是 1-2 組織樹（階層圖天然置中）
- 原則：邊欄恆定、舞台變化；分隔靠細線不靠陰影；只有真正的序列（流程步驟）才有編號；把大膽用在大數字上

## 對照「通用預設」後的修正
- 白底 + teal 產品風是需求指定，保留；但拿掉圓角卡片＋灰陰影套件，1-3 改為以細線分格的 3×2 表格
- 不用全大寫 eyebrow、不用「·」串接、不在按鈕文字後加 →（外連按鈕用 ↗ 表示「開新分頁」，是功能符號而非裝飾）
- 沒有進場動畫（圖表初次 render 關閉動畫）；唯一的動效是 2-1 前/後切換（回應使用者操作）
- 字體：Google Fonts 載入 Bricolage Grotesque + Noto Sans TC，是刻意的外部依賴（數字辨識度）；鍵盤另支援 Home / End；桌機每節用 min-height 而非固定 height，讓內容超出時仍可捲動
